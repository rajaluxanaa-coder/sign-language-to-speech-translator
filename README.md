# Real-Time Sign Language to Speech Translator

A real-time system that translates hand signs into spoken words using computer vision and deep learning.

## Features

- Real-time hand detection using MediaPipe (21 landmarks)
- LSTM neural network for sign classification
- Text-to-speech output using pyttsx3
- 96.67% recognition accuracy
- Works on any laptop with webcam

## Recognized Signs

- Hello
- Yes
- No

## Tech Stack

- Python 3.11.9
- OpenCV
- MediaPipe
- TensorFlow / Keras
- NumPy
- pyttsx3
